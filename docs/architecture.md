# Архитектура

Три процесса Electron.

1. **Main** открывает окно без системной рамки, помнит размер в `electron-store`, ставит CSP и меню. Заголовок рисует `custom-electron-titlebar`. На Windows кнопки окна остаются системным overlay. Чтение тегов синхронное и быстрое, запись уходит в utility process `electron/main/writer.ts`. Если процесс не поднялся, main пишет сам и шлёт тот же прогресс.
2. **Preload** публикует типизированный API: открыть файлы, прочитать теги, записать задания, путь из `File` через `webUtils.getPathForFile`, прогресс, обложка, копия, история и команды меню. Там же создаётся custom titlebar.
3. **Renderer** держит черновики в Zustand. `shared/plan.ts` сравнивает черновик с оригиналом и с флагами «Всем». Неизменённые поля в `WriteJob` не попадают.

Запись копирует файл во временный, правит копию и заменяет оригинал. Ошибка одного файла не отменяет остальные. Для занятого или доступного только для чтения файла интерфейс предлагает сохранить копию.

Слои интерфейса:

- `entities/track` — подписи, длительность, обложка
- `features/editor` — стор, drop-пути, подписки на меню и прогресс
- `widgets` — сайдбар, форма, нижняя панель, toast
- `app` — сборка экрана и токены
